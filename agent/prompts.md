# 硫芯·LitAgent —— 关键 Prompt 留档（AIGC 声明用）

> 本作品采用「规则编排 + 可选 LLM 润色」双模式。以下为实际使用的提示词原文（已脱敏），
> 同时保留离线模板生成逻辑，确保无密钥也能完整运行、结果可追溯。

## 1. 自然语言 → 结构化意图解析（可选 LLM 模式）

```
从用户句子中抽取锂硫电池材料研发意图，返回 JSON：
{"material": "材料名或null", "battery_type": "solid/liquid/null",
 "params": {"含量wt": 数值或null, "sa": 数值或null, "ps": 数值或null,
 "temp": 数值或null, "rate": 数值或null, "cycle": 数值或null}}。
可选材料列表（命中其一）：{candidates}。
用户原话：{user_text}
```

## 2. 性能预测调用（真实模型，agent_core.run_prediction）

```
给定填料 {encode_key}、类别 {category}、含量 {wt%}、比表面积 {m²/g}、粒径 {nm}、
基底/聚合物 {substrate}、膜厚 {μm}、温度 {°C}、压力 {MPa}、倍率 {C}、循环 {n} 圈，
调用 modeling.predict_single 预测固态锂硫电池的：
离子电导率(mS/cm) / 界面阻抗(Ω·cm²) / 初始比容量(mAh/g) /
容量保持率(%) / 库伦效率(%) / 电化学窗口(V)，并给出各指标不确定度与模型 R²。
```

## 3. 文献机理与实验方案生成（material_kb）

```
针对 {材料} 在锂硫电池中多硫化物锚定与 Li⁺ 传输的作用，
检索 material_kb 扩展知识库并总结：①材料特性；②核心优势；③主要短板；
④文献/代理依据；⑤推荐实验配置（基底/电解液/负载量/倍率/温度/制备建议）。
```

## 4. LLM 润色系统提示词（refine_narrative）

```
你是锂硫电池材料研发助理。下面会给到你一次材料性能预测的结构化结果
（输入参数、预测指标、知识库机理、推荐实验方案）。
请用简洁、专业、口语化的中文，把这些信息组织成一段给研究生/本科生看的
科研建议，重点说明：①预测了哪些性能、数量级是否合理；②材料起作用的可能机理；
③下一步实验怎么做。不要编造具体数字，用『约/估算』措辞，并提醒预测基于代理模型。
```

## 5. 离线模板生成（无 LLM 时默认，保证可复现）

见 `agent_core.nlg_offline`：按「性能预测 → 机理与文献依据 → 推荐实验方案 → 结论速览」
四段式拼接，所有数字直接来自模型输出，零外部依赖。
