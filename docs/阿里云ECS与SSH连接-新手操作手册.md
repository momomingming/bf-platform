# 阿里云 ECS 与 SSH 连接 — 新手操作手册

> 适用对象：第一次用云服务器、第一次 SSH 连接的用户。
> 目标：拿到一台 Ubuntu 22.04 的 ECS，用 SSH 连进去，为部署「硫芯LitAgent」平台做准备。
> 配套文档：`docs/迁移阿里云-资料清单与协作方案.md`

---

## 0. 先弄懂 5 个词（不懂这些后面会懵）

| 词 | 大白话 |
|---|---|
| **ECS** | 阿里云给你的一台"网上的电脑"。跟你自己电脑一样有 CPU、内存、硬盘、操作系统，只是放在阿里云机房。 |
| **公网 IP** | 这台网上电脑的"门牌号"。别人靠它找到你的服务器，比如 `123.45.67.89`。 |
| **SSH** | 一种"远程遥控"协议。你在自己电脑上敲命令，服务器执行。连上之后就像在操作服务器本机。 |
| **密钥对** | 登录用的"电子钥匙"，分两半：**私钥**在你手里（`.pem` 文件），**公钥**放在服务器上。只有配对的钥匙才能登录，比密码安全。 |
| **安全组** | 云端的"防火墙规则"。哪怕服务器开着 8501 端口，安全组不放行，外面照样访问不了。 |

**整体流程**：注册账号 → 建 ECS → 拿密钥 → 拿公网 IP → 放行端口 → SSH 连进去 → 交给阿屹部署。

---

## 1. 注册阿里云账号 + 实名认证

1. 打开 `https://www.aliyun.com`，点右上角「注册」，用手机号注册。
2. 注册完要**实名认证**（个人认证：身份证 + 人脸识别）。不实名买不了 ECS。
3. 绑定支付方式（支付宝即可）。按量付费会先冻结一小笔钱，正常。

> ⚠️ 学生如果想省钱：阿里云有「云翼计划/学生机」，认证学生身份后一年几十到一百多块。
> 但学生机常有规格和地域限制，先按普通 ECS 看，价格不合适再找学生机。

---

## 2. 创建 ECS 实例

进控制台：登录阿里云 → 顶部搜索框搜「ECS」→ 点「云服务器 ECS」→ 左侧「实例」→ 点「创建实例」。

按下面选，**每一项我都说明为什么**：

| 选项 | 选什么 | 为什么 |
|---|---|---|
| 付费模式 | 按量付费（先试）或包年包月（长期更便宜） | 刚迁移先按月/按量，跑通了再改包年。 |
| 地域 | 离你近的，如「华东1（杭州）」「华北2（北京）」 | 地域影响延迟和价格，无所谓具体哪个，选一个固定的就行。 |
| 可用区 | 默认随机 | 单台机器不用纠结。 |
| 实例规格 | **2 核 2G**（如 `ecs.e-c1m1.large` 或共享型 s6） | 现在腾讯云就是 2C2G，平迁够用；Linux 比 Windows 省内存。 |
| 镜像 | **Ubuntu 22.04 LTS 64位**（公共镜像） | Docker 生态最好，文档里的命令都基于它。**别选 Windows**。 |
| 系统盘 | 40GB ESSD 入门型（默认） | 够用，代码+DB+Docker 撑死几 GB。 |
| 公网 IP | **勾选"分配公网 IPv4 地址"** | 不勾就连不上、别人也访问不了。★关键 |
| 带宽计费 | 按使用流量，峰值 5Mbps | 够用又便宜。 |
| 安全组 | 新建，或选默认 | 后面手动加端口规则。 |
| 登录方式 | **密钥对**（推荐）→ 「创建密钥对」 | 比密码安全；密码容易被暴力破解。 |
| 实例名称 | 随便，如 `litagent-prod` | 方便认。 |

**创建密钥对**（在上表"登录方式"那一步）：

1. 点「创建密钥对」→ 名称填 `litagent-key`。
2. 创建后浏览器会**自动下载一个 `.pem` 文件**（如 `litagent-key.pem`）——这就是你的私钥，**只下载这一次**，丢了找不回来。
3. 把这个文件放到安全位置，推荐：`C:\Users\HJ\.ssh\litagent-key.pem`
   - 不要放桌面、下载目录（易丢/易被同步软件传走）。
   - `.ssh` 文件夹没有就手动建一个。
   - **这个文件绝对不能发给任何人，包括我。** 我要的是里面的内容做配置，不是私钥本身；真需要给我看的时候也只给我看路径/文件名，不给内容。

建完实例，等状态变成「运行中」。

---

## 3. 找到公网 IP

ECS 控制台 → 「实例」→ 点你刚建的那台 → 详情页里找：

- **公网 IP**：形如 `123.45.67.89` — 这个就是你要记下来给我的门牌号。
- 私网 IP：`172.x.x.x` 或 `10.x.x.x` — 这个是内网用的，**不用管**。

> 如果列表里公网 IP 显示"暂无"或空白：说明第 2 步没勾"分配公网 IPv4 地址"。
> 可以点「绑定弹性公网 IP（EIP）」补一个，或者直接删了重建。

把这个公网 IP 记下来。后面所有命令里 `<公网IP>` 都替换成它。

---

## 4. 配置安全组（放行 22 和 8501）

安全组 = 云端防火墙。要开两个端口：

- **22**：SSH 远程登录用。**不开就连不进去**。
- **8501**：平台网页访问用。**不开就浏览器打不开**。

步骤：

1. ECS 控制台 → 「实例」→ 点你的实例 → 左侧「安全组」→ 点那个安全组 ID。
2. 点「配置规则」→ 「入方向」→ 「手动添加」。
3. 添加两条：

| 规则 | 授权策略 | 协议/端口 | 授权对象 | 说明 |
|---|---|---|---|---|
| SSH | 允许 | TCP:22 | `0.0.0.0/0` | 允许任何地方 SSH 进来。⚠️ 稳妥做法是填你自己宽带的公网 IP，但家庭宽带 IP 会变，先用 `0.0.0.0/0`。 |
| 平台 | 允许 | TCP:8501 | `0.0.0.0/0` | 允许任何人访问 8501 网页。 |

> `0.0.0.0/0` 意思是"全世界"，先这么开跑通。以后要更安全可以收紧到你的 IP。

## 5. SSH 连接（重点，一步步来）

### 5.1 确认你电脑有没有 SSH 工具

Windows 10/11 自带 **OpenSSH 客户端**。验证：

1. 按 `Win + R`，输入 `powershell`，回车。
2. 在打开的窗口里输入 `ssh` 然后回车。
3. 如果出来一大段用法说明 → 有，能用。
4. 如果提示"不是内部或外部命令" → 没有，去「设置 → 应用 → 可选功能 → 添加功能」装「OpenSSH 客户端」。

### 5.2 连接命令

在 PowerShell 里输入（把 `<公网IP>` 换成你自己的 IP）：

```powershell
ssh -i C:\Users\HJ\.ssh\litagent-key.pem root@<公网IP>
```

逐个解释：

- `ssh` — 发起远程连接。
- `-i C:\Users\HJ\.ssh\litagent-key.pem` — 指定私钥文件（那个 `.pem`）。路径有中文或空格就加英文引号。
- `root@<公网IP>` — 用 `root` 账号连那台服务器。`root` 是 Linux 最高权限账号，Ubuntu 镜像默认用它登录。
  - 如果创建实例时你选的用户名不是 root，就把 `root` 换成那个用户名。

**第一次连接**会问你：

```
The authenticity of host '123.45.67.89 (123.45.67.89)' can't be established.
ED25519 key fingerprint is SHA256:xxxxx.
Are you sure you want to continue connecting (yes/no/[fingerprint])?
```

这是"第一次见面，确认要不要信任这台服务器"。输入 `yes` 回车。之后就不再问了。

连上后你会看到类似：

```
Welcome to Ubuntu 22.04 LTS ...
root@iZbp1xxx:~#
```

`root@...:~#` 这个提示符说明你**已经在服务器里了**。后面的命令都是在这台机器上执行。

### 5.3 断开连接

在服务器里输入：

```bash
exit
```

回车就回到你自己的电脑了。

## 6. 连上之后的基础命令（够用就行）

| 命令 | 作用 |
|---|---|
| `pwd` | 看现在在哪个目录 |
| `ls` | 看当前目录有什么文件 |
| `cd /opt` | 进入 `/opt` 目录（我们打算把项目放这） |
| `whoami` | 看当前用户，应该是 `root` |
| `uname -a` | 看系统信息，确认是 Ubuntu |
| `df -h` | 看硬盘剩余空间 |
| `apt update && apt upgrade -y` | 更新系统包（第一次连上建议跑一次） |
| `reboot` | 重启服务器 |

> Linux 里路径用正斜杠 `/`，不是 Windows 的反斜杠 `\`。
> `/` 是"根目录"，`/opt/litagent` 就是从根目录开始的一串文件夹。

## 7. 常见问题排查（连不上时按这个顺序查）

| 现象 | 大概率原因 | 怎么解决 |
|---|---|---|
| `Connection timed out`（超时） | 安全组没开 22，或 IP 写错 | 回第 3、4 步核对公网 IP 和安全组 22 规则。 |
| `Permission denied (publickey)` | 密钥不对/用户名不对 | ① 确认 `-i` 后面路径指到正确的 `.pem`；② 确认用户名是 `root`（或你建实例时选的那个）。 |
| `UNPROTECTED PRIVATE KEY FILE` | 私钥文件权限太开放（Windows 上偶尔出现） | 在 PowerShell 里执行：`icacls C:\Users\HJ\.ssh\litagent-key.pem /inheritance:r` 再执行 `icacls C:\Users\HJ\.ssh\litagent-key.pem /grant:r "%USERNAME%:F"` |
| `No such file or directory` 指 pem | 路径写错/文件名不对 | 到 `C:\Users\HJ\.ssh\` 里确认文件真实名字，注意 `.pem` 后缀别漏。 |
| 连上了但 `apt` 报错 | 系统刚装，源没更新 | 跑 `apt update` 再试。 |
| 浏览器打不开 `http://IP:8501` | 安全组没开 8501，或平台没启动 | 回第 4 步加 8501 规则；平台没起来时先看容器状态。 |

## 8. 关键配置速查表（连上后直接抄）

```bash
# ① 连上后第一件事：更新系统
apt update && apt upgrade -y

# ② 建项目目录
mkdir -p /opt/litagent

# ③ 确认能上网（应该输出一串 IP）
curl -I https://www.aliyun.com
```

**你需要交给我的信息（只有这 3 项）**：

1. **公网 IP**：`123.45.67.89` 这种格式。
2. **登录用户名**：一般是 `root`。
3. **密钥文件放在你本机的路径**：`C:\Users\HJ\.ssh\litagent-key.pem`（只告诉我路径，**不要发文件内容**）。

拿到这三项，后面装 Docker、拉代码、灌库、起容器、验证，全部我来给命令或代劳。

## 9. 安全提醒（这几条别犯）

- `.pem` 私钥 = 服务器钥匙，**任何人拿到都能登进你的服务器**。绝不外发、绝不传网盘、绝不截图。
- 阿里云账号开启 **MFA/二次验证**（控制台 → 账号安全设置）。
- 不用了就**停机**或删实例，按量付费一直开着会持续扣钱。
- 包年包月到期前记得续费，跟这次腾讯云过期一个道理。
- 服务器里别乱装来路不明的东西，root 权限很大，删错文件救不回来。

## 10. 一句话总结

> 建一台 Ubuntu 22.04 的 2C2G ECS → 勾选公网 IP → 用密钥对登录 →
> 安全组开 22 和 8501 → 记下公网 IP → 用 `ssh -i 密钥 root@IP` 连进去 →
> 把 IP 告诉我，剩下的我来做。
